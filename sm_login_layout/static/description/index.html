Background Login Layout

Give your login, signup, and password reset pages a professional, branded look with custom wallpapers, slideshows, day/night modes, and six ready-made layouts.

Key Features

Six Ready-Made Layouts

Choose from six beautiful layouts including a classic Centered Card, modern Split Screen, floating Glassmorphism Card, Right-Aligned Card, Shadowed Color Panel, and a branded Top Bar.

Select the layout that best fits your brand

Switch wallpapers by hour automatically

Day & Night Wallpaper Mode

Set different background wallpapers for day and night. The system checks the local clock of the visitor to automatically switch between day and night wallpapers.

Dynamic Wallpaper Slideshow

Upload multiple active wallpapers to run a smooth slideshow background. Customize the rotation interval in seconds right from the configuration dashboard.

Smooth transitions with adjustable speed

Overlay color, opacity, blur, card opacity

Fine-Tuned Styling Controls

Fine-tune the look with precision settings. Adjust the background blur radius, choose an overlay color and overlay opacity, set card opacity, and toggle company logo visibility.

Screenshots

Configuration Dashboard

All configurations are done in a dedicated form view. Enable custom layout, select design style, customize color overlays, opacity levels, slideshow speeds, day/night schedules, and upload wallpapers in a single place.
